# Tezos FA2 Token Contract (LIGO)

This is a minimal FA2 (TZIP-12) single-asset token contract in CameLIGO, suitable as a starting point for porting ERC-20 logic to Tezos.

## Usage
- Edit `fa2_token.mligo` to customize token name, symbol, and logic.
- Use [ligo](https://ligolang.org/docs/intro/installation/) to compile and deploy.
