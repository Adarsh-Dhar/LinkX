PRICING LOGIC:
─────────────────────────────────────────────────────────────────────────────

Testnet Price Fetch:
  1. Detect: is_testnet = (w3.eth.chain_id == 338)
  2. If testnet:
     a. Connect to: https://rpc.cronos.org (mainnet RPC)
     b. Load router ABI from: VVSRouter.json
     c. Router address: 0x145677FC4d9b8F19B4172A2b88f7fb1f02fdf220 (mainnet)
     d. Call: getAmountsOut(amount, [tokenIn, tokenOut])
     e. Result: Real amounts from mainnet liquidity
  3. Fallback if connection fails:
     Use estimated rates: 1 USDC ≈ 502,402 VVS


TRANSACTION LOGIC:
─────────────────────────────────────────────────────────────────────────────

Testnet TX Simulation:
  1. Generate mock hash: hashlib.sha256(wallet+amount+time)
  2. Estimate gas: ~120,000 gas × current gas price
  3. Create mock result with:
     - "status": "success_mock"
     - "tx_hash": "0x1a2b3c..."
     - "block_number": 123456789 (simulated)
     - "gas_cost": Estimated CRO amount

Mainnet TX Real:
  1. Build real transaction via router
  2. Sign with: web3.eth.account.sign_transaction()
  3. Send with: w3.eth.send_raw_transaction()
  4. Wait for: w3.eth.wait_for_transaction_receipt()
  5. Return actual blockchain data
